# AgentCenter name and icon

The code, the icon file included, is free software under the
[AGPL-3.0-or-later](LICENSE). The license grants no trademark rights (its
section 7(e), in [NOTICE](NOTICE)): the name and the icon, used as marks, tell
people where a build comes from, so they stay with this project.

Covered here: the name "AgentCenter", the application id
`io.github.eduardopin.AgentCenter`, and the icon in `data/icons/`.

## You may, without asking

- Say your project is "based on AgentCenter", "a fork of AgentCenter" or
  "compatible with AgentCenter".
- Use the name in articles, talks, reviews, tutorials and package listings
  that ship this project unmodified.
- Keep the name in a fork's source history, NOTICE and credits.

## You may not, without written permission

- Ship a modified version, or a work based on this code, under the name
  AgentCenter, under the same application id, or with the icon.
- Use a name or icon close enough to be confused with AgentCenter.
- Suggest that your build is official or endorsed by this project.

A fork picks its own name, application id and icon, keeps the NOTICE file,
and shows "Based on AgentCenter by Eduardo José Pin" in its About dialog (the
section 7 terms in [NOTICE](NOTICE)).

To ask for permission, open an issue on the repository.
